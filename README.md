# Крафт-калькулятор рынка Crossout

Неофициальный фанатский сайт для расчёта выгоды крафта и торговли на рынке Crossout.
Данные рынка берутся из открытого API [CrossoutDB](https://crossoutdb.com).

## Что умеет

- **Каталог** предметов с поиском, фильтрами по редкости, категории и фракции и сортировкой по ценам и ликвидности. Колонка «Перепродажа» показывает, сколько можно заработать, купив через запрос и выставив предложение.
- **Калькулятор крафта** на странице предмета: полное дерево рецепта, для каждого компонента сравнение «купить» и «скрафтить», автоматический выбор самого дешёвого варианта и ручное переключение. Показывает себестоимость, прибыль с продажи с учётом комиссии и экономию по сравнению с покупкой готового.
- **Выгодные крафты**: все крафтовые предметы, отсортированные по прибыли или марже, с фильтром по ликвидности.
- **График цены** за 14 дней.
- Общие настройки: покупать сразу или через запрос, продавать сразу или через предложение, размер комиссии. Сохраняются в браузере.

## Запуск

```bash
npm install
npm run dev        # реальные данные, запросы идут через прокси Vite на crossoutdb.com
npm run dev:mock   # выдуманные тестовые данные, интернет не нужен
npm test           # тесты расчётов
npm run build      # сборка в dist/
```

## Публикация

Сайт статический (папка `dist/`), его можно выложить на Cloudflare Pages, Vercel, Netlify или GitHub Pages.

API CrossoutDB вызывается через небольшой прокси на Cloudflare Workers (`worker/index.ts`). Он кэширует ответы на 5–15 минут, чтобы не нагружать чужой сервис, и добавляет CORS-заголовки.

```bash
npx wrangler login
npm run worker:deploy                 # выведет адрес вида https://crossout-craft-proxy.<имя>.workers.dev
VITE_API_BASE=https://crossout-craft-proxy.<имя>.workers.dev/api npm run build
```

## Устройство

- `src/api/normalize.ts` — всё знание о формате ответов CrossoutDB. Автор API предупреждает, что формат может меняться, поэтому чинить нужно будет только этот файл.
- `src/lib/craft.ts` — расчёты: себестоимость, «купить или скрафтить», прибыль, рейтинг крафтов. Покрыт тестами.
- `src/pages/` — страницы каталога, предмета и выгодных крафтов.

## Допущения

- Цены в API хранятся в сотых долях монеты и делятся на 100.
- У ресурсов цена указана за лот (обычно 100 шт.), в рецептах количество в штуках.
- Комиссия рынка при продаже по умолчанию 10%.
- Платы за верстак в API нет, её можно ввести вручную на странице предмета.
